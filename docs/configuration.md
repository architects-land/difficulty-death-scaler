# Configuration

The mod can be configured via gamerules.
Every gamerule starting with the prefix `dds:` was added by the mod.

## Player difficulty

`dds:enable_temp_ban` enables the temp ban (default: `true`).

`dds:death_before_temp_ban` sets the number of death before a ban (default: `5`).

`dds:temp_ban_duration` sets the temp ban's duration in hour (default: `12`).

## Passive difficulty

`dds:enable_passive_difficulty` enables the [passive difficulty](/difficulty/passive) (default: `true`).

## Bounty

`dds:enable_bounty` enables the [bounty](/other/bounty) (default: `true`)

## Redacted

`dds:enableRedacted` enables the REDACTED features (default: `true`)
