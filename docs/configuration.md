# Configuration

The mod can be configured via gamerules.
Every gamerule starting with the prefix `dds:` was added by the mod.

## Player difficulty

`dds:enableTempBan` enables the temp ban (default: `true`).

`dds:deathBeforeTempBan` sets the number of death before a ban (default: `5`).

`dds:tempBanDuration` sets the temp ban's duration in hour (default: `12`).

## Passive difficulty

`dds:enablePassiveDifficulty` enables the passive difficulty (default: `true`).
