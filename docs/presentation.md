# Presentation

Difficulty Death Scaler is a *server-side* mod completly overhauling how the difficulty works.

Each time a player dies, the difficulty could be increased.
This can reduce the maximum number of hearts, increase the dangers of mobs, or disable the F3.
Basically, more you die, more you will die.

There are three difficulties in the mod:

- [Global difficulty](/difficulty/global) which is for every player
- [Player difficulty](/difficulty/player) which is per player
- [Passive difficulty](/difficulty/passive) which is relative to the distance of the world's center and the time passed

Many aspects of these difficulties can be configured via gamerules.
Check [Configuration](/configuration) for more information.

The mod is providing a command to get information about these difficulties.
Check [Commands](/other/commands) for more information.
